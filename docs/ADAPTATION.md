# 搭建自己的流程

先阅读 [三队列差异与来源](../skills/gestational-weight-cleaning/references/cohorts.md) 与 [可移植入口契约](PORTABLE.md)。

## 建议模块及依赖
| 模块 | 输入证据 | 行为/人工检查 |
|---|---|---|
| 身份与孕天对齐 | 孕次、来源记录主键、LMP或可靠孕天 | 输出唯一记录键与匹配冲突；同一女性多孕次分组 |
| 显式单位转换 | 来源单位说明 | kg保留、斤转kg、混合单位标记 |
| 全局/阶跃修复 | 全轨迹、身高、独立分娩记录 | 区分整段与孤立错误，逐项记录依据 |
| 孕前基线仲裁 | 孕前自报、建册实测、早孕时点 | 保留来源；缺独立证据时跳过，不制造day=0 |
| 局部尖峰扫描 | 个人时序与邻居 | 候选列表、人工检查；可使用去趋势MAD作为补充 |
| 产后边界 | 可信分娩孕天/日期 | 标记与孕期分析排除分开；推断标记与已知时间分开 |
| 尾部异常 | 晚孕轨迹、胎数、基线 | 根据条件启用，缺失关键依据则报告未执行 |
| 人工复核/重建 | 稳定记录键、旧值、理由 | 回放并校验版本，重算BMI |
| 最终质控 | 各阶段输出 | 行数/孕次数/缺失率/修正与删除数、抽样复核 |

portable 已实现身份字段验证、显式单位转换、局部候选筛查、已知分娩边界、人工动作与审计。
其余模块由 Agent 根据数据条件实现；仓库根目录的 01–12 脚本保留为历史算法参考。
旧脚本中硬编码的输入、输出路径与人工校正版文件名须逐项适配，不能仅按文件编号串行执行。
旧 GUI 可通过选择 CSV 或其 --help 指定输入；portable 输出使用新字段，使用旧 GUI 前应显式适配列与日志格式。

## 一次适配的交付清单
字段映射；各模块启用理由；输入输出依赖图；可复现命令；合成例子；修正日志；失败/冲突清单；
按真实高BMI、缺基线、稀疏记录、重复孕天和产后记录分层的人工抽检；未完成核验事项。
阈值敏感性比较应报告保留/修改/删除的差异，医学判断交由具备相关领域知识的人员复核。

## 使用不同 Agent
支持 skill 的 Agent：将 skills/gestational-weight-cleaning 整个目录复制或链接到该工具的技能目录，保留 references。
不支持 skill 的工具：直接提供 SKILL.md 和需要的引用文件，说明仓库位置；本 skill 无平台专属工具依赖。
示例任务：
> 阅读 skills/gestational-weight-cleaning/SKILL.md。我的 CSV 包含孕次ID、记录ID、孕天、体重和身高，没有可靠孕前体重。
> 请检查数据契约，基于 portable 编写字段映射和必要模块，保留真实时点，给出合成测试及复核清单。
