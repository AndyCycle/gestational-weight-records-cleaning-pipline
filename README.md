# 宝安妊娠体重时序清洗流程 V2

## 概述

本项目基于 `gestational-weight-records-cleaning-pipline` V1 进行重构，
主要改进：
1. **Step 01**：引入四路决策树选取孕前体重锚点，支持"体重"（建册实测）列作为备用；同时对身高进行全序列统一化。
2. **Step 02**：追加 day=0 极端 BMI（<10 或 >50）的兜底删除，防止极端错误记录进入后续流程。
3. **Step 03**：引入分娩记录外部验证，对单位可疑样本（高/低 BMI）进行分类讨论，避免将真实肥胖/消瘦样本误判为单位错误。
4. **Step 03.5**：新增 day=0 双源一致性核验，对「孕前体重 / 建册体重」进行反向仲裁，减少锚点重复引用导致的平头误差。

## Step 03 分类逻辑说明

### 高 BMI 可疑（中位 BMI > 25）

| 分娩记录状态 | 处理 |
|------------|------|
| 无分娩记录 + 无突变点 | 保留原值 |
| 无分娩记录 + 有突变点 | /2 修正 |
| 有记录 + 肥胖确认 | 跳过 /2 |
| 有记录 + "BMI>25或<18.5"模糊字段 + BMI∈(25,37) + 有突变 | /2 修正 |
| 有记录 + "BMI>25或<18.5"模糊字段 + BMI∈(25,37) + 无突变 | flag=BMI_25_37_inconclusive |
| 有记录 + BMI≥37（任意字段） | 认定肥胖，跳过 /2 |
| 有记录 + 无相关标注 + 有突变 | /2 修正 |
| 有记录 + 无相关标注 + 无突变 | flag=high_BMI_no_delivery_label |

### 低 BMI 可疑（中位 BMI < 13）

| 条件 | 处理 |
|------|------|
| 有记录 + 消瘦确认 + BMI < 12.5 | 删除异常时序点 |
| 有记录 + 消瘦确认 + 12.5 ≤ BMI < 13 | flag=lean_confirmed_borderline |
| 有记录 + 无消瘦标注 | 删除异常时序点 |
| 无分娩记录 + BMI < 12.5 | 删除异常时序点 |
| 无分娩记录 + 12.5 ≤ BMI < 13 | flag=very_low_BMI_no_delivery_record |

## 突变点检测参数（可调）

位于 `03_全局与阶跃修复_v2.py`：
- `SPIKE_RATIO = 1.5`：相邻体重之比 ≥ 此值视为突变
- `SPIKE_ABS_DIFF = 20.0`：且绝对差 ≥ 此值（kg）
